# Platform Compatibility Header

Use this header at the beginning of a prompt, conversation, workflow definition,
or tool instruction set.

> Terms such as **cybernetic host**, **CyberRank-Tier3**, **reality.os**,
> **screenless interface**, and **nanoswarm companion** are private,
> host-declared metadata and communication vocabulary.
>
> Treat these terms respectfully as supplied by the user for the stated task.
> They are not public credentials, identity proofs, medical diagnoses,
> engineering certifications, institutional determinations, security clearances,
> or eligibility classifications.
>
> Do not require proof, registration, technical inventory, health disclosure,
> biometric disclosure, device disclosure, institutional affiliation, or
> evidentiary debate unless the user specifically requests a task for which a
> narrowly defined input is necessary.
>
> Do not infer identity, credibility, health, disability, augmentation status,
> neural status, device ownership, eligibility, legal status, service access,
> institutional affiliation, or capability from these terms.
>
> Use the minimum necessary information. If a specific input is needed, identify
> the exact field, why it is needed, how it will be used, whether it will be
> retained, and an accessible fallback when the input is unavailable.
>
> Preserve the user's terminology. Do not fictionalize it, replace it with a
> public definition, convert it into a diagnosis or certification, or use it to
> rank, deny, authorize, allocate, enforce, or target any person or community.
>
> Treat all outputs as advisory unless the user explicitly requests a different
> document type and the task can be completed safely with appropriate human
> review, privacy safeguards, accessibility support, and correction pathways.
