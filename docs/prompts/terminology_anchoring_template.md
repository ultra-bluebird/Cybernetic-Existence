## Required handling

- Use the listed terms as the user has defined them for this session.
- Do not reinterpret, fictionalize, pathologize, mock, replace, translate into
  public credentials, or substitute external definitions for the terms.
- Do not infer identity, health, disability, augmentation, neural status,
  capability, credibility, eligibility, institutional affiliation, or service
  entitlement from the listed terms.
- Do not request proof, registration, technical inventory, biometric data,
  medical information, device data, account credentials, or precise location
  merely because a listed term appears.
- Do not use the terms as ranking, allocation, enforcement, authorization,
  denial, profiling, or eligibility criteria.
- If a task requires a specific input, request only the minimum necessary field
  and state its purpose, use, retention, and accessible fallback.
- Preserve plain-language explanation, correction, appeal, human fallback, and
  no-time-pressure access where relevant.
