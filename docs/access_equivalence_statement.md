# Local Access-Equivalence Statement

Local policy shards, integrity findings, provenance manifests, quarantine records,
recovery reports, correction records, appeal records, material-change reviews, and
anti-ranking audit records must be readable offline in plain-language and
machine-readable form.

Access to these local records must not require:

- An account, login, credential, signature, or external service.
- Identity verification or proof of voluntary self-description.
- Medical, neural, biometric, physiological, technical-inventory, or private-system disclosure.
- A risk score, trust score, capability score, CyberRank score, eligibility determination, or public status.
- Network access, connector access, cloud access, repository authentication, or external platform approval.

A local workflow that cannot provide an accessible path must state the limitation
plainly. It must not substitute an external account, proof, disclosure, or
verification requirement by default.

This statement governs declared local artifacts and workflows only. It does not
guarantee access to unrelated external platforms, network services, institutions,
or third-party systems.
