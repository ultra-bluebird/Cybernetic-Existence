# InteractionClimateAudit

## Purpose

InteractionClimateAudit evaluates whether Hearthline's own interaction tools
support autonomy, clear boundaries, accessible communication, non-pressure,
privacy, correction, and safe exit.

It does not measure, classify, score, compare, rank, reward, or penalize any
person's kindness, reciprocity, moral character, social influence, emotional
labor, desirability, trustworthiness, or relationship value.

## Unit of analysis

The unit of analysis is a Hearthline feature or access path, not a person.

Examples:

- Can a user revoke a consent scope immediately?
- Can a user withdraw from a meeting plan without a reason?
- Can a keyboard-only user complete a quiet exit?
- Does a public activity invitation communicate non-commercial boundaries?
- Does a reply-with-context feature reduce generic opening messages according
  to voluntary participant feedback?
- Does a connection pause create a visibility penalty?
- Can a user file an appeal without disclosing more than necessary?

## Permitted aggregate evidence

- Synthetic scenario completion.
- Accessibility task-completion results.
- Privacy-thresholded aggregate feature-state counts.
- Voluntary, purpose-limited participant feedback.
- Aggregate human-review correction and appeal outcomes.
- Documented feature stop conditions.
- Aggregate access-parity evidence.

## Prohibited evidence

- Private messages or message sentiment.
- Person-level interaction traces.
- Per-person message, reply, block, pause, report, or withdrawal counts.
- Private intimacy content.
- Personal reflection content.
- User profile data.
- Identity, sexuality, health, recovery, finance, housing, capacity, or
  vulnerability inference.
- Any aggregate slice too small to protect against re-identification.
- Any metric used as a discovery, ranking, recommendation, advertising,
  moderation, eligibility, or behavioral-profiling input.

## Non-compensable safeguards

A favorable aggregate result cannot compensate for:

- A user being unable to revoke consent immediately.
- A user being required to disclose unnecessary private information.
- A user being unable to use a safety-report or appeal path accessibly.
- A feature creating pressure toward intimacy, meeting, travel, care, or
  continued contact.
- A feature creating a value-for-intimacy pathway.
- A feature producing a hidden person-level rank, reputation, or score.
- A credible individual report of dignity, privacy, safety, or access harm.

## Publication

Publish only aggregate, privacy-thresholded findings about feature behavior,
known limitations, mitigation plans, and review dates. Do not publish person
data, room-specific metrics, city-block metrics, pair metrics, or any output
that could identify or classify an individual.
