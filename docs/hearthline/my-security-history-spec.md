Screen title: My privacy and security history

Visible entries:
- “A privacy choice changed” with date and local time.
- “An unsent suggestion became unavailable under your current privacy choices.”
- “A sign-in method was added.”
- “A sign-in method was removed.”
- “A specific action was paused briefly for account protection.”
- “That action is available again.”
- “You requested a review.”
- “A review was completed.”

Never visible in this screen:
- Recovery status.
- A list of fields that were revoked.
- Exact fraud thresholds.
- Another person’s profile details.
- Raw technical telemetry.
- The contents of an invalidated suggestion.
- Any indicator that another user filed a report.

Controls:
- View plain-language explanation.
- Save a local copy of account history that contains no sensitive content.
- Request review for an active action pause.
- Pause new connection activity.
- Update privacy choices.
