Cryptographic Sovereign Binding and Consensus Security

Roots of Trust

CCxTrust establishes user-controlled trust system by combining black-box Root of Trust (RoT) from TEE with white-box RoT of TPM, creating unified trust framework.

PUF Attestation

Janus uses Physically Unclonable Functions (PUF) as intrinsic Root of Trust, providing physics-based trust resistant to side-channel attacks and chip delayering.

TPM Key Attestation

TPM key attestation cryptographically proves that RSA private key in certificate request is protected by Trusted Platform Module, enabling secure certificate issuance.

CCxTrust is a confidential computing platform that establishes a user-controlled trust system by combining the black-box Root of Trust (RoT) from a Trusted Execution Environment (TEE) with the white-box RoT of a Trusted Platform Module (TPM). This collaborative approach unifies disparate trust roots into a single, user-managed framework, decoupling trust from hardware vendors.

Key Innovation: The Composite Attestation protocol combines static measurements from the TEE and dynamic measurements from the TPM into a single, unified attestation report.
